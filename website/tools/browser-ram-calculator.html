Frequently Asked Questions

Why do modern browser tabs consume so much RAM even when idle?

Unblocked web pages spawn 15 to 40 third-party ad-auction iframes and background WebSocket telemetry timers that continuously allocate JavaScript heap memory even when the tab is in the background.

How do SWEEPR DeepBlock and Total Tab & RAM Tamer reduce memory usage?

SWEEPR DeepBlock blocks ad and tracker scripts at the C++ network layer before they allocate DOM heap memory (~185 MB saved per heavy tab), while the Total Tab & RAM Tamer module hibernates inactive background tabs and Sweepr Desktop Cleaner reclaims system cache.
