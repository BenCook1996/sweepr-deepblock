Browser Architecture
Manifest V3 declarativeNetRequest (DNR)

Manifest V3 declarativeNetRequest (DNR) is the modern Chromium extension network-filtering API where extensions register declarative JSON rule tables evaluated natively by the browser C++ network stack rather than intercepting every URL inside a JavaScript background page.

Network Tracking
CNAME Cloaking Trackers

CNAME cloaking is an evasion technique where a website points a first-party subdomain (such as metrics.publisher.com) to a third-party tracking vendor using a DNS CNAME record so browsers treat third-party tracking cookies as first-party.

Browser Fingerprinting
HTML5 Canvas Fingerprinting

HTML5 Canvas Fingerprinting is a stateless tracking technique that instructs your browser to draw hidden 2D text and shapes on an element and hashes the resulting pixel array via toDataURL() to create a persistent hardware identifier.

Encrypted DNS
DNS-over-HTTPS (DoH)

DNS-over-HTTPS (DoH, RFC 8484) is a security protocol that encrypts Domain Name System (DNS) resolution queries inside standard HTTPS TLS traffic on port 443 rather than sending plaintext UDP packets on port 53.

A Consent Management Platform (CMP) implementing the IAB Transparency and Consent Framework (TCF v2.2) is the pop-up dialog used by publishers to request GDPR/UK-GDPR permission to share your data with hundreds of programmatic ad vendors.
