1. Physical Ergonomics & Thumb-Zone Architecture

Legacy mobile VPN interfaces place the Connect orb and server selector in the upper-middle canvas, forcing a two-handed grip on 6.7"–6.9" Pro Max / Ultra devices. Our redesigned layout anchors 100% of primary interactive controls inside the bottom 58% natural thumb arc while reserving the top 42% for high-contrast, passive telemetry (`tabular-nums` IP, latency, and throughput).

Viewport Zone Height Allocation Assigned UI Components Touch Target Spec
Top Zone (Passive) Top 18% Brand Header, Connection Status Pill, Dynamic Island Read-only (Zero required taps)
Middle Zone (Glanceable) Middle 24% Virtual IPv4, `tabular-nums` Latency/Timer, Live Throughput Graph Optional tap-to-copy IP (`48x48dp`)
Bottom Zone (Thumb Arc) Bottom 58% Master Connect CTA, Quick Server Pill, Bottom-Anchored Search, 4-Tab Nav 56–64px height + 10px gap
